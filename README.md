# vignan_hackthon-balzers

RoamAgent is an agentic travel platform designed for Indian intercity travel.

## Features
- Spring Boot 3.2.x Backend with Java 21
- PostgreSQL & Flyway Migrations
- Deterministic Time-Expanded Graph Routing Engine
- Groq AI Integration (`llama-3.1-8b-instant`) with Offline Fallback Parsing
- Mid-trip Disruption Recovery & Atomic Revision Commits
